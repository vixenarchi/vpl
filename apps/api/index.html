vpl · api

One door for the suite. POST /chat forwards a model request from our own origin, because model APIs do not send CORS headers. POST /search does the same for evidence: Tavily or Serper, one query, a few results with sources.

The key travels in the request body, is used once, and is never stored or logged. Only the hosts on the allowlist are reachable, search destinations are fixed per provider, and only the apps of this suite may call either door.
